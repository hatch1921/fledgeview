FledgeView is made by one photographer, Frank Hatcher, and I read every message myself. Questions, problems and ideas are all welcome.

To help me sort out a problem quickly, include:

  • Your FledgeView version (Help ▾ → What’s new) and whether you use the website or FledgeView for Windows
  • Your system and browser, for example Windows 11 with Chrome
  • For raw files: the camera model
  • What you did, what happened, and a screenshot if you can

The easiest way: in FledgeView, choose Help ▾ → Contact support. It opens an email with your version and system already filled in.

FledgeView for Windows

FledgeView for Windows is sold through the Microsoft Store, so Microsoft handles payment, downloads and updates. To install it on another PC, or again after resetting Windows, open the Microsoft Store, sign in with the same Microsoft account, and find FledgeView in your Library.

Refunds are handled by Microsoft under its own rules: see Get a refund for apps and games purchased from Microsoft Store. If something isn’t working, please email me first; it may be a quick fix.
